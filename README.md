# Project-Impetus

## A technical 2D physics puzzle game prototype on UE5.
A technical demo showcasing the feasibility and gameplay potential of combining two major gameplay mechanics: propulsion-based movement and grapple tether, in a two-dimensional, top-down, zero-gravity environment for new, inventive physics puzzle possibilities. This combination of gameplay mechanics allow you to interact with elements to solve puzzles.
